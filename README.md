# Market Legends

Trivia de finanzas en español. App web (HTML/JS) para estudiantes.

## Cómo abrir el juego
Doble clic en `index.html` (Chrome o Safari). Funciona sin internet.

En iPhone: abrir la liga publicada en Safari → Compartir → "Agregar a pantalla de inicio".

## Cómo seguir trabajándolo con Claude Code
1. Abre una terminal (PowerShell) en esta carpeta.
2. Escribe `claude` y pide, por ejemplo: "sigamos con Market Legends, lee CLAUDE.md".
3. Claude Code lee `CLAUDE.md` y sabe en qué va el proyecto.

## Archivos
- `index.html` — el juego (diseño original v5 con logo Market Legends).
- `CLAUDE.md` — contexto completo del proyecto para Claude Code.
- `preguntas.json` — banco de preguntas editable (empezar a llenar aquí).
- `manifest.json`, `sw.js`, `icons/` — lo que hace que se instale como app en el teléfono.

## Nota
`index.html` está construido sobre el diseño original (`trivia_legends_v5.html`, copia en `original/`).
`banco_general_1865.json` guarda las 1,865 preguntas de trivia general del juego de 2017.
